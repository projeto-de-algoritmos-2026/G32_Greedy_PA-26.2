📦 Carregar o Caminhão

Problema: O caminhão tem capacidade limitada de peso e volume. Maximize o valor total dos pedidos carregados. Mochila Fracionária — O(n log n)

💡 Critério Guloso
Ordenar por densidade (valor/peso) em ordem decrescente. Pegar cada item inteiramente enquanto houver espaço; fracionar o último se necessário.
Θ(n log n) — ordenação domina
Caminhão
0 kg / 500 kg
✅ Resultado Otimizado
Pseudocódigo
sort items by (value/weight) DESC
remaining ← capacity
total_value ← 0
for each item i in sorted order:
  if item.weight ≤ remaining:
    take item fully
    remaining -= item.weight
    total_value += item.value
  else:
    fraction ← remaining / item.weight
    take fraction of item
    total_value += fraction × item.value
    break
return total_value

⛽ Rota de Abastecimento

Problema: O caminhão precisa chegar ao cliente mais distante. Defina o menor número de paradas de combustível. Problema do Caminhoneiro — O(n)

✅ Paradas Planejadas
💡 Critério Guloso
Sempre viajar o máximo possível com o combustível atual. Parar apenas quando o próximo posto não é alcançável.
Θ(n) — varredura linear
Pseudocódigo
current ← 0; stops ← []
while current < destination:
  next_reachable ← farthest station ≤ current + tank
  if no station reachable AND current + tank < dest:
    return IMPOSSIBLE
  if next_reachable == destination or 
     current + tank ≥ destination:
    break
  stops.append(next_reachable)
  current ← next_reachable
return stops

📅 Escala de Entregas

Problema: Clientes pedem janelas de horário específicas. Com um motorista disponível, atenda o máximo de entregas possível. Interval Scheduling — O(n log n)

✅ Entregas Selecionadas
💡 Critério Guloso
Ordenar por horário de término. Selecionar entrega se seu início é ≥ ao fim da última selecionada.
Θ(n log n) — ordenação domina
Pseudocódigo
sort intervals by finish time
selected ← []
last_finish ← -∞
for each interval i in sorted order:
  if i.start ≥ last_finish:
    selected.append(i)
    last_finish ← i.finish
return selected

👷 Alocação de Docas

Problema: Todas as entregas do dia precisam ser realizadas. Quantas docas/motoristas são necessários no mínimo? Interval Partitioning — O(n log n)

✅ Alocação Calculada
💡 Critério Guloso
Ordenar por horário de início. Para cada entrega, alocar à primeira doca disponível (cujo término ≤ início atual). Se nenhuma disponível, abrir nova doca.
Θ(n log n) — min-heap de docas
Pseudocódigo
sort intervals by start time
docks ← min-heap (by finish time)
for each interval i:
  if docks not empty AND 
     docks.min.finish ≤ i.start:
    reassign earliest-free dock to i
  else:
    open new dock for i
  docks.push(i)
return num_docks

⏰ Ordem de Despacho

Problema: Cada pedido tem um prazo (deadline) e tempo de execução. Minimize o maior atraso na fila de despacho. Atraso Máximo / EDF — O(n log n)

✅ Resultado EDF
💡 Critério Guloso
EDF — Earliest Deadline First: Processar sempre o pedido com prazo mais próximo. Minimiza o atraso máximo de forma ótima.
Θ(n log n) — ordenação por deadline
Pseudocódigo
sort jobs by deadline (d_i) ASC
time ← 0; max_lateness ← 0
for each job j in EDF order:
  start ← time
  finish ← time + j.exec_time
  lateness ← max(0, finish - j.deadline)
  max_lateness ← max(max_lateness, lateness)
  time ← finish
return max_lateness

💰 Caixa COD

Problema: Cliente paga a entrega em dinheiro. Calcule o troco com o mínimo de cédulas e moedas. Problema da Caixa — O(n)

💡 Critério Guloso
Sempre escolher a maior denominação que cabe no valor restante. Funciona para sistemas canônicos (como o Real brasileiro).
Θ(n) onde n = nº de denominações
Configure os valores e clique em Calcular Troco
Pseudocódigo
change ← paid - price
denominations ← [100, 50, 20, 10, 5, 2, 1,
                  0.50, 0.25, 0.10, 0.05, 0.01]
result ← {}
for each d in denominations:
  count ← floor(change / d)
  if count > 0:
    result[d] ← count
    change -= count × d
return result

🗜️ Compressão de Rastreio

Problema: Comprimir os códigos de rastreio dos pedidos antes de enviar ao sistema central, economizando armazenamento e banda. Código de Huffman — O(n log n)

✅ Resultado da Compressão
💡 Critério Guloso
Fila de prioridade mínima: sempre combinar os dois nós com menor frequência. Resultado: árvore de prefixo ótima com códigos de comprimento variável.
Θ(n log n) — heap de prioridade
Pseudocódigo
freq ← count frequency of each char
Q ← min-heap of (freq, char) nodes
while |Q| > 1:
  left ← Q.extract_min()
  right ← Q.extract_min()
  parent ← new node(left.freq + right.freq)
  parent.left ← left
  parent.right ← right
  Q.insert(parent)
root ← Q.extract_min()
codes ← assign_codes(root, "")
